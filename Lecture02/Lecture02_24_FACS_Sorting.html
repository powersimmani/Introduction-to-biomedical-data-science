Purity Mode
Goal: Maximum purity (>99%)
Strategy: Tight gates, conservative droplet selection
Yield: 50-70% recovery
Use: Downstream cloning, rare cell isolation
Yield Mode
Goal: Maximum recovery
Strategy: Broader gates, include doublets
Purity: 85-95%
Use: Cell expansion, functional assays
Single Cell Mode
Goal: One cell per well
Strategy: Index sorting with imaging
Efficiency: ~80-90% single cells
Use: scRNA-seq, clonal analysis
⚠️ Critical Quality Control Steps
Before Sorting:
  • CST (Cytometer Setup & Tracking) beads
  • Nozzle verification (70-100 μm)
  • Drop delay optimization
  • Compensation matrix setup
  • Stream stability check (<5% CV)
  • Laser alignment and power
After Sorting:
  • Reanalysis of sorted population
  • Purity verification (>95% expected)
  • Viability assessment (Trypan blue)
  • Cell count and recovery rate
  • Document sort parameters
  • Back-gating analysis
Advanced Applications
• Single-cell genomics: scRNA-seq, scATAC-seq
• Rare cell enrichment: CTCs (1 in 10⁹)
• Stem cell isolation: HSCs, iPSCs
• Immunophenotyping: 18+ parameter sorting
• Functional sorting: Secretion, calcium flux
• Organoid dissociation: Live cell sorting
Common Troubleshooting
• Low purity: Check drop delay, gate position
• Poor viability: Reduce pressure, use cold buffer
• Clogging: Filter sample (40 μm), reduce concentration
• Unstable stream: Check sheath fluid level, nozzle
• Low yield: Optimize flow rate, check sort logic
• Doublets: Dilute sample, use singlet gate
