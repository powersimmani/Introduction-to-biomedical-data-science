Detailed Flow Cytometry Principles
💧 Hydrodynamic Focusing Mechanism

Principle

  • Sample core stream surrounded by sheath fluid
  • Laminar flow prevents mixing
  • Cells align in single file
  • Typically 5-10 μm spacing between cells

Critical Parameters

  • Flow rate: 10-100 μL/min
  • Sheath pressure: 10-60 psi
  • Core/sheath ratio: 1:10 to 1:100
  • Nozzle diameter: 50-200 μm
🔬 Optical Detection System

Light Scatter Parameters

Parameter Detection Angle Information Applications
FSC (Forward Scatter) 0-10° Cell size/volume Size gating, debris exclusion
SSC (Side Scatter) 90° Internal complexity, granularity Cell type discrimination, activation state
💡 Key Concept: FSC is proportional to cell surface area or diameter, while SSC increases with cytoplasmic granularity, nuclear lobulation, and membrane irregularity.

Fluorescence Detection Channels

Common Fluorophores

  • FITC: 488 nm excitation, 530 nm emission
  • PE: 488/561 nm excitation, 575 nm emission
  • APC: 640 nm excitation, 660 nm emission
  • Pacific Blue: 405 nm excitation, 450 nm emission

Detection Components

  • PMTs: Photomultiplier tubes amplify signal
  • Dichroic mirrors: Separate wavelengths
  • Bandpass filters: Isolate specific emission
  • Longpass filters: Block shorter wavelengths
⚙️ Spectral Overlap & Compensation
⚠️ Critical: Fluorophore emission spectra overlap! Without compensation, signal from one fluorophore can "spill over" into other detection channels, creating false positives.

Compensation Process

Steps for Compensation

  1. Single-stained controls: Prepare cells stained with only one fluorophore
  2. Measure spillover: Determine % of signal in off-target channels
  3. Calculate matrix: Create compensation matrix
  4. Apply correction: Subtract spillover mathematically
Formula:
Corrected FL1 = Measured FL1 - (α × Measured FL2)
where α = spillover coefficient

Gating Strategy

Sequential Gating Approach:
  1. FSC vs SSC: Exclude debris and doublets
  2. FSC-A vs FSC-H: Singlet discrimination
  3. Viability marker: Exclude dead cells (e.g., 7-AAD, DAPI)
  4. Lineage markers: Identify cell populations of interest
  5. Functional markers: Assess activation, differentiation, etc.
✅ Quality Control & Best Practices

Daily QC

  • Run calibration beads
  • Check laser alignment
  • Verify PMT voltages
  • Clean fluidics system
  • Document CV% of bead populations

Sample Preparation

  • Single-cell suspension (<1% clumps)
  • Optimal concentration: 10⁶-10⁷ cells/mL
  • Filter through 35-70 μm mesh
  • Keep on ice to preserve viability
  • Vortex before acquisition
⚠️ Common Pitfalls to Avoid:
  • Over-compensation or under-compensation
  • Insufficient single-stain controls
  • Aggregated or clumped cells
  • Photobleaching from prolonged light exposure
  • Inappropriate gating strategy
