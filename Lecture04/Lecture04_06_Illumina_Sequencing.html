Detailed Principles & Examples
1. Bridge Amplification Mechanism

What it is: Bridge amplification is a solid-phase PCR technique that generates millions of identical DNA clusters from a single molecule on the flow cell surface.

How it works:

  • The flow cell surface is densely coated with two types of oligonucleotides (P5 and P7 primers)
  • DNA fragments with complementary adapters bind to these surface-bound primers
  • The DNA strand bends over like a bridge and binds to the adjacent primer
  • DNA polymerase extends from the primer, creating a double-stranded bridge
  • The bridge is denatured, and both strands can form new bridges
  • After 35 cycles, each original molecule creates ~1,000 identical copies in a tight cluster

Why it matters: This amplification provides enough signal intensity for accurate base detection while maintaining spatial organization. Each cluster occupies approximately 1 µm², allowing billions of clusters per flow cell.

2. Reversible Terminator Chemistry

The Core Innovation: Each nucleotide carries two special modifications:

  • Removable fluorescent dye: Each of the four bases (A, T, G, C) has a unique fluorescent label
  • Reversible 3'-OH blocking group: Prevents multiple nucleotides from being added in one cycle

The Sequencing Cycle:

  • Incorporation: Modified nucleotides compete to bind to the template. DNA polymerase adds the correct complementary base. The 3'-OH block prevents further extension.
  • Imaging: High-resolution cameras capture fluorescent signals from millions of clusters simultaneously. Each color corresponds to a specific base.
  • Cleavage: Chemical treatment removes both the fluorophore and the 3'-OH block in a single step.
  • Iteration: The process repeats for the next position, building the sequence one base at a time.

Why this is revolutionary: Unlike earlier methods, this allows all four nucleotides to be present simultaneously, increasing speed and reducing error. The reversible terminator ensures only one base is added per cycle, providing precise control.

3. Quality Metrics & Error Sources

Phred Quality Score (Q-score):

Each base call receives a quality score indicating confidence:

  • Q30 = 99.9% accuracy (1 error per 1,000 bases)
  • Q40 = 99.99% accuracy (1 error per 10,000 bases)
  • Formula: Q = -10 × log₁₀(P), where P is error probability

Common Error Sources:

  • Phasing: Some DNA strands in a cluster fall behind or jump ahead, causing signal decay over cycles
  • Cross-talk: Fluorescent signal bleeding between adjacent clusters or wavelength channels
  • Incomplete cleavage: Residual fluorophores or blocking groups from previous cycles
  • GC bias: High GC content regions may have reduced amplification efficiency

Quality Control Strategies:

  • Real-time quality monitoring during sequencing
  • Trimming low-quality bases from read ends
  • Using paired-end reads for error detection
  • Requiring high depth of coverage for variant calling
Real-World Applications
Whole Genome Sequencing (WGS)
Use case: Complete human genome sequencing
Coverage: 30-60× depth typical
Read length: 2×150 bp paired-end
Total reads: ~1 billion per genome
Application: Clinical diagnostics, population studies, rare disease identification
RNA Sequencing (RNA-seq)
Use case: Gene expression profiling
Coverage: 20-50 million reads
Read length: 2×75 or 2×100 bp
Key feature: Quantifies transcript abundance
Application: Cancer research, drug response studies, developmental biology
Targeted Sequencing
Use case: Specific gene panels or exomes
Coverage: 500-1000× depth
Read length: 2×150 bp
Target size: 50 kb - 60 Mb
Application: Cancer mutation panels, inherited disease screening, pharmacogenomics
Metagenomics
Use case: Microbial community profiling
Coverage: Variable, 1-10 Gb typical
Read length: 2×250 bp for 16S, 2×150 for shotgun
Key challenge: Distinguishing closely related species
Application: Microbiome studies, environmental monitoring, pathogen detection
4. Recent Innovations & Future Directions

Current Advances:

  • Patterned flow cells: Ordered nanowells instead of random clustering, increasing density by 4-6×
  • Two-color chemistry: Reduces imaging time by using only 2 fluorophores instead of 4
  • Sequencing by binding (SBB): Next-generation chemistry eliminating the need for amplification
  • Deep learning base calling: AI models improve accuracy, especially in homopolymer regions

Emerging Applications:

  • Single-cell multi-omics (simultaneous DNA, RNA, protein profiling)
  • Spatial transcriptomics with subcellular resolution
  • Long-read sequencing integration for complete genome assembly
  • Direct detection of epigenetic modifications
  • Real-time pathogen identification for clinical diagnostics

Cost trajectory: The cost of sequencing a human genome has dropped from $100 million (2001) to under $1,000 (2024), largely driven by Illumina's technology improvements.
